# pymario-fetch
A modern system-fetch script written in Python on Manjaro Linux, featuring custom ASCII art and system specs formatting.

# Pymario System Fetch 🚀

Un'applicazione in **Python moderno** sviluppata su **Manjaro Linux** che estrae le informazioni reali del sistema operativo in uso e le formatta all'interno del terminale, accompagnate da una firma personalizzata in ASCII Art.

---

## 🎨 Anteprima dell'Output

Quando esegui lo script nel terminale, vedrai una schermata simile a questa:

```text
pymario@manjaro-workspace
-------------------------
  _____  __   __
 |  __ \ \ \ / /

 | |__) | \ V / 
 |  ___/   \ /  

 | |       | |  
 |_|       |_|  
    
OS:       Manjaro Linux
Kernel:   6.x.x-MANJARO
Shell:    /bin/bash
Python:   3.11.x
Project:  GitHub / Pymario22
Status:   Ambiente di sviluppo pronto su Manjaro 🚀
```

---

## 🛠️ Tecnologie Utilizzate

* **Linguaggio Core:** Python 3 (Framework nativo senza dipendenze esterne)
* **Moduli Built-in:** `platform`, `os`, `sys`
* **Ambiente di Sviluppo:** Manjaro Linux
* **Integrazione Web:** Sincronizzato con l'hub ufficiale su Altervista e il profilo TikTok

---

## 🚀 Come Eseguire lo Script su Linux

Se vuoi testare lo script in locale sul tuo terminale, segui questi passaggi:

1. **Clona la repository:**
   ```bash
   git clone https://github.com
   cd pymario-project
   ```

2. **Avvia il file principale:**
   ```bash
   python src/main.py
   ```
